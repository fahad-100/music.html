# 🎸 The Guitar Garage (HTML Project)

A beginner-level static website created using only **HTML** and **inline CSS**. This was my **first institute project** during my early front-end development learning phase.

## 🚀 Overview

This project showcases a fictional guitar store called **The Guitar Garage**. It includes various sections like Home, Gears, Specialty Collection, Membership, and About Us — all designed and structured using raw HTML and inline styles.

## 🛠️ Technologies Used

- HTML5
- Inline CSS only (no external or internal stylesheet)
- Basic image assets

## 📌 Features

- Simple, static UI structure
- Inline CSS used for learning purposes
- Includes multiple pages: Home, Gears, Services, About, etc.
- Header navigation with marquee elements
- Product showcase in grid layout

## ⚠️ Note

This project is **not responsive** because it was built using **only inline CSS** for learning basics. Making it responsive would require a complete refactor with external CSS or a framework like Tailwind or Bootstrap.

However, the code is well-structured and displays properly on desktop viewports.

## 🎯 Purpose

This project was created as part of a **6-month Front-End Development course** at my institute. It was my first hands-on website to understand page structure, layout, and inline styling.
